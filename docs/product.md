# ExploreOS 产品设计

## v0.3 实现补充（2026-10-06）

增加探索向导，根据精力、可用时间、接触方式和方向生成一个可退出的小行动。建议只有在用户确认后才转为实验或问题。

确认保存的数据除 localStorage 外，还通过仅监听本机的服务原子写入 `data/exploreos-latest.json`，更新前状态保存在 `data/exploreos-previous.json`。浏览器副本为空而本机有记录时只提示恢复，不自动覆盖；恢复前仍下载当前浏览器副本。

## v0.2 实现补充（2026-09-15）

在下述初始原则之上，增加统一探索手记、编辑、检索、可恢复移除、自动草稿、问题转实验与记忆卡文字导出。评分属于可选字段，默认折叠；复盘显示均值及真实评分条数。数据仍为 version:1，各实体可带可选 `deletedAt`；实验移除时仅隐藏子项，恢复后重新显示。单独移除的子项不会随父实验自动恢复。记忆中的记录快照保持独立。

备份包含回收站，草稿另存于浏览器。旧记录无需迁移。暂不提供永久删除与附件上传。

## 为什么存在

想尝试不同的人生方向，却担心零散探索没有积累。产品帮助用户把好奇变成小实验，把经历变成可回看的证据，逐步认识自己、增加选择权。

核心问题不是“AI 能否给我正确的人生答案”，而是“这次尝试让我知道了什么”。首个用户是自己，先验证是否愿意使用、是否减少纠结。

初始化日期：2026-09-09。以自由探索为原则，固定周分配、强制晋级和硬性投入规则不纳入本版。

## 产品原则

1. **No Exploration Is Wasted**：成功、暂放、不适合，都留下经历、认知、记忆和能力线索。
2. **探索不应该成为另一种工作**：允许休息和没有进展。10 小时只是可调整的参考，不是配额。
3. **证据先于身份判断**：一次讨论只能形成低置信度假设，不能证明适合某职业。
4. **地图由真实经历点亮**：创建方向或讨论想法不等于获得技能。保留走过但不想继续的路。
5. **决定由本人做出**：系统整理资料，不按分数自动淘汰方向。

## 核心循环

好奇 → 方向 → 待验证假设 → 小实验 → 行动与感受 → 复盘决定 → 记忆卡 → 新的好奇。

- 人生地图：展示自己选择的方向。区分待探索、有记录、已归档；未知不代表失败。
- 小实验：回答一个具体问题，而非决定一生。预算可空，无截止日期要求。
- 探索记录：行动必填；时间、投入感、成就感、继续意愿、认知、技能标签可选。不把未知值当作零分。
- 复盘：直接展示记录、投入和发现。用户填写结论与原因，再选择继续、暂放或归档。三种结果都可保留记忆卡。
- 记忆卡：保存复盘时的实验标题、时间、记录、认知和决定快照。之后新增记录不改写旧卡片。
- 技能线索：汇集用户在真实记录中填写的标签，保留来源次数；没有自动等级。
- 问题库：记录生活中的问题、当前解决方式和不满意的地方，为下一次实验提供素材。

## 数据模型

| 实体 | 主要字段 | 关系 |
|---|---|---|
| Direction | id、name | 一个方向有多个实验 |
| Experiment | id、directionId、title、hypothesis、budget、status、createdAt | 状态 active / hold / archived |
| Session | id、experimentId、date、action、minutes、feeling、achievement、again、insight、skills | 一次真实记录，数值允许未知 |
| Memory | id、experimentId、title、decision、reflection、sessions、createdAt | 复盘快照，不覆盖历史 |
| Problem | id、text、workaround、createdAt | 独立问题线索 |

使用带版本号的 JSON 导出，恢复时严格校验结构与关联。恢复替换当前数据前由用户确认，并下载当前备份。存储失败时提示，不能显示为保存成功。

## 首次体验

默认建立产品设计、AI 产品、写作、视频创作、技术服务五个方向。这些是原对话线索，不预填实验结果。用户可自由添加方向，初始所有方向均显示“待记录”；历史起点另存文档，不自动换算成时长或技能。

建议第一个实验：“试着设计 ExploreOS 的核心体验”，假设：“我可能更喜欢设计产品机制，而非纯实现”。预算可参考 10 小时，也可以不设。记录后观察自己是否主动想继续，是否觉得记录有价值。

## 本版验收

- 可新建方向与实验，刷新后保留。
- 可记录行动、可选时长与评分；没有评分时不生成虚假数字。
- 可暂停、归档、重新开启实验，历史记录持续存在。
- 复盘生成快照；之后追加记录不会修改旧记忆。
- JSON 导出与恢复可往返；损坏或关联不完整的数据不会覆盖现有数据。
- 移动屏幕可操作，表单有标签，弹窗可用键盘关闭，输入内容作为文本渲染。
- 不显示逾期、落后、连续天数或强制配额。

## 后续 AI 的位置

未来可以辅助追问、发现模式、提出下一次小实验。任何结论都要列出记录来源、相反证据与不确定性。区分“不熟悉工具”“讨厌过程”“暂时疲惫”，不将少量评分写成性格或职业诊断。本版先不实现自动推断。
