# ExploreOS · 人生探索

> No Exploration Is Wasted. 没有一次真实探索是浪费。
>
> 探索不应该成为另一种工作。

ExploreOS 是一个能记录真实探索的本地网页应用，目前为 v0.3：从好奇出发，通过引导、小实验、探索手记和复盘记忆，逐步认识自己。

## v0.3 新增

- 新增「探索向导」：根据当下精力、可用时间、接触方式和想靠近的方向，给出一项可以立即开始的小探索。
- 每项建议包含推荐原因、具体步骤、完成标准和退出条件；低精力时允许十分钟后停止，高精力时提供可选加一步。
- 建议可以换一项、预填为小实验，或先放进问题口袋。浏览建议不会自动写入任何个人记录。
- 首页增加「带我去看看」入口；已有方向、实验和备份仍使用原有 `version:1` 数据格式。
- 每次确认保存后同步写入 `data/exploreos-latest.json`，并保留 `data/exploreos-previous.json`；浏览器资料或端口变化后可在「数据备份」中恢复。

## v0.2

- 编辑方向、实验、探索记录和问题；首页直接继续实验、回看最近片段。
- 独立「探索手记」，按关键词、方向和实验状态查找内容。
- 记录表单默认只展示基本内容，时长、评分与技能可展开填写；关闭或刷新后可继续草稿。
- 回收站与即时撤销：移除实验会同时隐藏其记录和记忆，恢复实验后重新显示；单独移除的条目保持在回收站。
- 复盘显示有样本数量的评分摘要，未知评分不计入平均值；记忆卡可导出 Markdown。
- 问题可预填为一个小实验，原问题继续保留。
- 同一浏览器多页面变动会同步显示；正在编辑的旧表单会提示核对，避免覆盖新内容。

旧版记录和 JSON 备份可直接使用，数据格式仍为 `version:1`。

## 开始使用

在本目录运行 `node server.mjs`，然后打开 http://localhost:4173 。需要 Node.js 18 或以上，无需安装依赖。npm 正常时也可以使用 `npm start`。

1. 在「人生地图」选择一个好奇的方向，或添加自己的方向。
2. 创建一个小实验：写下想验证的问题，预算可以留空。
3. 实际尝试后记录做了什么、感受和发现，时间与评分都可留空。
4. 随时复盘，选择继续、暂放或归档。生成的记忆卡保留经历和证据。
5. 在「数据备份」导出 JSON；换浏览器前备份，再在新浏览器恢复。

没有每日任务、连续签到、排行榜、强制时长或自动职业判定。停止一个方向不会抹去它。

## 项目文件

- `docs/product.md`：原则、核心流程、数据模型、版本范围、验收标准。
- `docs/roadmap.md`：后续验证与迭代方向。
- `templates/`：可以独立于网页使用的探索、复盘、问题记录模板。
- `index.html`、`styles.css`、`app.js`、`model.js`：本地网页原型。
- `server.mjs`：仅监听本机的静态服务器。
- `tests/model.test.mjs`：数据校验和复盘逻辑测试。运行 `node --test tests/model.test.mjs`（或 `npm test`）。

## 数据与当前边界

数据保存在当前浏览器，同时由本地服务镜像到项目的 `data/` 目录，不上传；该目录已被 Git 忽略。清理浏览器数据后可以尝试从本机副本恢复，但仍建议定期导出 JSON 到其他位置。导出的文件包含个人记录，请自行保管。初始方向为可修改的示例，不包含已投入时长、技能等级、实验成果或评分。

回收站在「数据备份」中，条目不会自动清空；JSON 备份包含回收站。草稿单独保存在此浏览器，不包含在 JSON 备份中。已有记忆卡保存复盘时的快照，编辑或移除原始记录不会改写旧卡片。方向下有关联实验时可重命名，但不能直接移入回收站。

本版没有接入大模型、账户、云同步或附件上传；复盘摘要由你的记录直接整理，不是 AI 推断。技能标签由你填写，按真实记录汇集，不代表能力认证。更换访问地址或端口会使用不同的浏览器存储。
