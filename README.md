# ExploreOS · 人生探索

> No Exploration Is Wasted. 没有一次真实探索是浪费。
>
> 探索不应该成为另一种工作。

ExploreOS 是一个能记录真实探索的本地网页应用，目前为 v0.6：从好奇出发，通过引导、随手记、小实验和复盘记忆，逐步认识自己。

## v0.6 新增

- 小实验可补充「下一步准备做什么」和「做到哪里就够了」，都可留空。向导保存为实验时保留具体步骤和完成标准，后续可以编辑。
- 尚未整理的随手记可直接「新建实验并整理」：一次保存创建实验与探索记录，保留原文和日期，时长与评分留空。没有已有实验时，「整理到实验」也会进入这个流程。关闭表单只保存草稿，不提前整理。
- 问题转实验时保留来源关系；问题卡片展示相关实验和当前状态，实验可返回原问题。相关条目移除后提示回收站入口，恢复后关联继续可用。旧实验不会按标题猜测或补写来源。
- 复盘可留下一个下次的小行动，同时更新实验并存入记忆快照；首页的继续实验卡片显示下一步，实验内可回看最近复盘。清空下一步不会清除旧记忆，暂停和归档也不要求填写行动。
- 新记忆保留复盘时的问题、完成标准与下一步，支持检索与 Markdown 导出。之后编辑实验或记录不会改写快照。
- 问题、随手记、向导的实验草稿各自保存，避免不同来源共用一个新实验草稿。旧 JSON 备份仍可使用，新增字段按可选项严格校验。

## v0.5 新增

- 探索手记支持关键词、方向、记录类型和日期范围组合筛选；可只看尚未整理的随手记，一键清除所有筛选。日期范围包含起止当天，日期颠倒时提示调整。
- 随手记与整理后的探索记录可相互跳转，直接定位原文；关联记录或实验移入回收站时显示恢复入口，仍禁止重复整理。
- 手记和技能来源中的实验标题可点击回看，按 ID 打开对应实验，同名实验也能准确区分；可返回全部实验。
- 检索包括方向、实验标题、行动、发现和技能标签。筛选仅影响显示，切换页面时重置，不写入个人记录与备份。
- 浏览器测试统一使用独立临时目录和端口，测试数据不会写入个人本机备份。更新后重启本地服务并刷新页面。

## v0.4 新增

- 「随手记」只需写一句话，不用先建方向或实验；支持草稿、编辑、搜索和回收站，包含在 JSON 与本机备份中。
- 可以把随手记整理到已有实验：新增一条探索记录，同时保留原文及整理标记，不重复整理，也不虚构时长和评分。
- 探索向导按方向提供不同的具体行动，增加生活、艺术与摄影、运动、职业体验入口；浏览建议不会创建方向，确认保存实验时才建立新方向。
- 可以标记建议为感兴趣、暂时不想、已经试过。后两类在当前组合中暂不推荐，可以随时重新看看；反馈随备份保存。
- 本机保存使用版本校验：旧浏览器不能悄悄覆盖不同的新副本。冲突时保留浏览器记录，页面提示核对；主动覆盖前先确认并下载本机副本。
- 每个成功保存的版本按日期保留到 `data/history/`，支持从页面恢复；恢复前先下载当前浏览器副本。历史不自动清理，仍建议导出到另一处。
- 页面顶部显示本机保存时间或同步问题。更新代码后需要重启本地服务并刷新页面。

## v0.3 新增

- 新增「探索向导」：根据当下精力、可用时间、接触方式和想靠近的方向，给出一项可以立即开始的小探索。
- 每项建议包含推荐原因、具体步骤、完成标准和退出条件；低精力时允许十分钟后停止，高精力时提供可选加一步。
- 建议可以换一项、预填为小实验，或先放进问题口袋。浏览建议不会自动写入任何个人记录。
- 首页增加「带我去看看」入口；已有方向、实验和备份仍使用原有 `version:1` 数据格式。
- 每次确认保存后同步写入 `data/exploreos-latest.json`，并保留 `data/exploreos-previous.json`；浏览器资料或端口变化后可在「数据备份」中恢复。

## v0.2

- 编辑方向、实验、探索记录和问题；首页直接继续实验、回看最近片段。
- 独立「探索手记」，按关键词、方向和实验状态查找内容。
- 记录表单默认只展示基本内容，时长、评分与技能可展开填写；关闭或刷新后可继续草稿。
- 回收站与即时撤销：移除实验会同时隐藏其记录和记忆，恢复实验后重新显示；单独移除的条目保持在回收站。
- 复盘显示有样本数量的评分摘要，未知评分不计入平均值；记忆卡可导出 Markdown。
- 问题可预填为一个小实验，原问题继续保留。
- 同一浏览器多页面变动会同步显示；正在编辑的旧表单会提示核对，避免覆盖新内容。

旧版记录和 JSON 备份可直接使用，数据格式仍为 `version:1`。

## 开始使用

在本目录运行 `node server.mjs`，然后打开 http://localhost:4173 。需要 Node.js 18 或以上，无需安装依赖。npm 正常时也可以使用 `npm start`。

1. 在「人生地图」选择一个好奇的方向，或添加自己的方向。
2. 创建一个小实验：写下想验证的问题，预算可以留空；愿意时补充一个具体行动和完成标准。问题和随手记也可以作为起点。
3. 实际尝试后记录做了什么、感受和发现，时间与评分都可留空。
4. 随时复盘，选择继续、暂放或归档；可留一个下次的小行动。生成的记忆卡保留经历、证据和当时的计划。
5. 在「数据备份」导出 JSON；换浏览器前备份，再在新浏览器恢复。

没有每日任务、连续签到、排行榜、强制时长或自动职业判定。停止一个方向不会抹去它。

## 项目文件

- `docs/product.md`：原则、核心流程、数据模型、版本范围、验收标准。
- `docs/roadmap.md`：后续验证与迭代方向。
- `templates/`：可以独立于网页使用的探索、复盘、问题记录模板。
- `index.html`、`styles.css`、`app.js`、`model.js`、`journal.js`：本地网页原型及记录筛选逻辑。
- `server.mjs`：仅监听本机的静态服务器。
- `tests/*.test.mjs`：数据校验、复盘、记录筛选和本机备份测试。运行 `node --test tests/*.test.mjs`（或 `npm test`）。
- 浏览器验证：设置 `PLAYWRIGHT_MODULE` 为已有 Playwright 的 `index.mjs` 绝对路径后运行 `node tests/browser-suite.mjs`（或 `npm run test:browser`），需要本机 Microsoft Edge；测试会自行启动隔离服务。可在命令末尾指定单项，例如 `browser-review.mjs`。

## 数据与当前边界

数据保存在当前浏览器，同时由本地服务镜像到项目的 `data/` 目录，不上传；该目录已被 Git 忽略。清理浏览器数据后可以尝试从本机副本恢复，但仍建议定期导出 JSON 到其他位置。导出的文件包含个人记录，请自行保管。初始方向为可修改的示例，不包含已投入时长、技能等级、实验成果或评分。

回收站在「数据备份」中，条目不会自动清空；JSON 备份包含回收站。草稿单独保存在此浏览器，不包含在 JSON 备份中。已有记忆卡保存复盘时的快照，编辑或移除原始记录不会改写旧卡片。方向下有关联实验时可重命名，但不能直接移入回收站。

本版没有接入大模型、账户、云同步或附件上传；复盘摘要由你的记录直接整理，不是 AI 推断。技能标签由你填写，按真实记录汇集，不代表能力认证。更换访问地址或端口会使用不同的浏览器存储。
